# 🕒 Relógio Digital Online

Um relógio digital minimalista, rápido e responsivo, desenvolvido com HTML5, CSS3 e JavaScript puro. O projeto conta com uma interface moderna inspirada no GitHub e uma camada inicial de verificação para acesso.

## 🚀 Funcionalidades
- **Design Responsivo:** Adaptado perfeitamente para telas de computadores e dispositivos móveis.
- **Modo Seguro / Captcha Simulado:** Tela inicial interativa de verificação antes de exibir o relógio.
- **Atualização em Tempo Real:** Exibe horas, minutos, segundos e a data formatada em português.
- **Otimizado contra bugs de codificação:** Totalmente compatível com UTF-8 e livre de caracteres corrompidos.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estruturação)
- **CSS3** (Estilização e Flexbox)
- **JavaScript (Vanilla)** (Lógica do relógio e manipulação do DOM)
